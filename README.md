# 云贝中心 · 科研补给原型

用户端：https://dafeiww.github.io/yunbei-center/

管理员：https://dafeiww.github.io/yunbei-center/admin.html

## 当前玩法

- 充值配置：管理员创建充值活动，设置活动名称和充值折扣（1–9 折），档位手动添加（最多 8 个，支持 0 元档），每行实时显示到账云贝与折后实付；保存并启用后自动同步用户端。
- 自定义金额：充值页"自定义金额"卡片内置输入框，默认显示"自定义金额"文案，输入后实时换算到账云贝与折后实付，并同步支付二维码。
- 确认明细：扫码区按钮改为"确认明细"，弹窗核对原价、折扣、到账与实付，确认支付后自动跳转充值订单页。
- 充值订单：成功、失败订单均可追溯；充值成功的订单支持勾选并合并开票，列表上方实时显示已选笔数与合计金额，与发票管理保持同步。
- 云贝签到：每天签到得 1 云贝，本周任选 5 天，每人每周最多 5 云贝；第 3 次额外解锁绘图体验。
- 云贝任务：邀请好友（双方各得 10 云贝）、完善个人中心 3 云贝、绑定微信 3 云贝、上传头像 1 云贝，任务卡片带图标设计。
- 管理界面：充值活动管理、签到与首充配置、云贝任务配置、发票申请管理、运营统计，均与用户端实时同步。
- 既有权益：已参与的签到周、首充补给和邀请保留参与时规则，后续配置调整用于新一轮或新参与用户。

## 体验入口

index.html 是用户首页，admin.html 直接进入管理员界面。页面右上角也可切换演示角色；在同一入口中切换角色，可验证配置对用户端的影响。

旧的「云贝中心-分享版.html」与「.htm」链接同步更新。两个「云贝科研补给」独立文件也可下载后离线打开，无需附带其他文件。

玩法扩展代码保存在 assets/supply-prototype.* 和 assets/supply-admin.*，完整操作与配置规则见 [科研补给原型说明](科研补给原型说明.md)。

当前为交互演示：支付、绘图、好友行为和开票均为模拟操作，数据保存在浏览器；不同入口、设备或浏览器之间不会自动同步。
