# 云贝中心

面向绘图与分析场景的积分兑换交互原型。

- 侧边栏：云贝中心、发票管理。
- 初始余额 3,000 云贝；示例换算 100 云贝 = 1 元。
- 高级图表、存储扩容、AI 解读、高清导出、算力和协作权益兑换。
- 北京时间自然周累计签到，奖励 5、5、10、5、15、5、25 云贝。
- 兑换记录、云贝明细、单笔和批量开票申请。
- 待开票、申请中、已开票各准备 10 条历史示例；每页 10 条。
- 已开票记录和详情页可下载 PDF 示例。
- 支持手机浏览，体验数据保存在当前浏览器。

直接打开 index.html 即可使用，请保留 assets 目录。也可通过 GitHub Pages 访问。

本项目为前端交互演示，未接入真实支付、权益或税务开票服务；下载 PDF 明确标记为示例。

PDF 生成功能使用 pdf-lib，相关 MIT 许可证位于 assets/pdf-lib-LICENSE.md。
