# 云贝中心

在线页面：https://dafeiww.github.io/yunbei-center/

双击 index.html 可离线打开，需保留 assets 文件夹。初始余额 3,000 云贝，体验数据保存在当前浏览器。

- 充值：1 元兑换 10 云贝；首笔充值八折，支付原价 80%。
- 充值档位：10 / 50 / 100 / 300 / 500 / 1000 元；赠送比例为 0% / 2% / 5% / 8% / 12% / 20%。首充优惠可叠加赠送。例如首充 100 元实付 80 元，到账 1,050 云贝。
- 签到：北京时间自然周累计，七次奖励为 5、5、10、5、15、5、25 云贝，共 70 云贝，每日限领一次。
- 邀请：复制专属邀请码；首次好友注册奖励邀请者 100 云贝，其后每位 50 云贝，新好友 20 云贝。每月最多奖励 20 位，重复注册不奖励。注册流程为演示。
- 使用看板：支持最近 7 / 30 / 90 天及自定义日期、消费趋势、分类占比、明细和导出。
- 兑换：高级图表、存储扩容、AI 分析、高清导出、算力和协作权益；奖励云贝优先使用。
- 发票：仅已支付的充值订单可以申请，按实付金额开票；赠送、签到、邀请和兑换均不可开票。已开票示例支持下载 PDF。
- 我的兑换保留 30 条历史示例，生效中 16 条、已到期 14 条；充值发票示例为待开票、申请中、已开票各 10 条。示例不会计入真实账户余额或看板。

这是可交互前端原型。支付、注册、权益发放和税务开票均为演示，未接入真实服务。正式上线须接入账户认证、服务端积分账本、支付回调和开票服务。邀请码当前仅在当前浏览器持久保存。

图表采用本地附带 Apache ECharts，PDF 使用本地附带 pdf-lib；可离线运行。
