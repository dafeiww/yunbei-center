# 云贝中心

在线体验：https://dafeiww.github.io/yunbei-center/

面向桌面网页的可交互原型。黑色导航、橙色主色调；云贝中心为一级目录，包含云贝充值、云贝明细、兑换商城、邀请好友，另设发票管理。支持普通用户与管理员两种演示角色。

## 当前功能

- **云贝充值**：展示账户余额和充值档位，云贝数在上、金额在下。默认1元兑换10云贝，默认档位8折；每个档位可分别配置原价、赠送和折扣。原价10元、100云贝、0赠送、8折时，实付8元、到账100云贝。
- **扫码演示**：页面内显示微信/支付宝共用的演示二维码、5分钟倒计时及支付确认。二维码不具备真实收款功能。
- **签到**：按北京时间自然周累计，每日一次，七次奖励为5、5、10、5、15、5、25云贝；本周最多70云贝。
- **云贝明细**：收入包含充值、签到、邀请；支出包含空间扩容、项目分享和绘图。收入用蓝色、支出用橙色，支持筛选、分页和导出。
- **兑换商城**：50 GB空间扩容、项目分享增加5人，保留5:2封面比例。管理员可管理分类、商品、封面、价格及上架状态。
- **邀请好友**：仅使用专属邀请链接。好友必须为从未注册过基因云的新用户；注册成功后邀请人得完整10云贝、新用户得10云贝，邀请人数不限。提供历史示例记录与分页。
- **发票管理**：只有已支付的充值订单可申请，按实付金额开票；赠送、签到、邀请和兑换不另行开票。待开票、申请中、已开票均有示例，已开票可下载PDF。PDF参考普通电子发票票样，保留演示水印；销售方与税率为演示数据，不作为报销或税务凭证。
- **后台配置**：新增充值档位后生成列表，最多6档；新增档位默认关闭。金额、赠送和1–9折实付实时计算，启用后同步前台。商城配置独立管理。
- **保留功能**：我的兑换与使用看板保留实现，当前导航隐藏，可按需恢复。

## 离线打开与分享

直接打开或转发 `云贝中心-分享版.html`（或`.htm`），无需附带其他文件。`github-release/index.html`为同一完整页面，用于GitHub Pages发布。

源码入口`index.html`依赖同目录下的`assets`。运行`node build-standalone.cjs`可重新生成独立分享文件。

初始可用余额3000云贝。资料与配置仅保存在当前浏览器，角色切换、支付、邀请注册、权益发放和开票均为演示；跨设备不会自动同步。正式系统应接入真实登录权限、服务端积分账本、支付回调与税务开票服务。

## 本次视觉调整

沿用用户提供的金色云贝轮廓与勾选造型，优化为矢量图，加入充值余额区与邀请宣传插图。兑换卡片恢复三列紧凑宽度；下载发票整理为红色票面标签、黑色数据的普通电子发票布局。

图表使用Apache ECharts，PDF使用pdf-lib，依赖均随页面打包，可离线运行。
