# 云贝中心 · 科研补给原型

用户端：https://dafeiww.github.io/yunbei-center/

管理员：https://dafeiww.github.io/yunbei-center/admin.html

## 当前玩法

- 每周签到：每个自然周任选 5 天参与，无需连续；默认奖励为 5、5、10、10、40 云贝，第 3 次额外解锁绘图体验。
- 首次充值：按档位配置享首充优惠，后续充值按原价计算，档位赠送保留。首充额外开启三个七天周期的进阶补给，每周期完成一次绘图或分析后领取权益。
- 邀请好友：新好友注册、首次绘图和次周回访三个阶段，双方默认分别获得 10、20、20 云贝；回访需注册满 7 天，每位邀请人每月默认最多 20 位。
- 管理界面：保留充值档位与商城管理，新增签到补给、首充补给、邀请奖励配置与奖励记录；支持实时预览、保存配置及记录导出。
- 模拟支付：成功弹窗统一显示到账、实付、余额、补给和开票信息，底部只保留一组主要操作；适配电脑和手机。
- 列表展示：商城价格与对应金额单行排列；邀请列表提供注册、首图、回访三条带标记的示例，示例奖励不计入余额或月度名额。
- 既有权益：已参与的签到周、首充补给和邀请保留参与时规则，后续配置调整用于新一轮或新参与用户。

## 体验入口

index.html 是用户首页，admin.html 直接进入管理员界面。页面右上角也可切换演示角色；在同一入口中切换角色，可验证配置对用户端的影响。

旧的「云贝中心-分享版.html」与「.htm」链接同步更新。两个「云贝科研补给」独立文件也可下载后离线打开，无需附带其他文件。

玩法扩展代码保存在 assets/supply-prototype.* 和 assets/supply-admin.*，完整操作与配置规则见 [科研补给原型说明](科研补给原型说明.md)。

当前为交互演示：支付、绘图、好友行为和开票均为模拟操作，数据保存在浏览器；不同入口、设备或浏览器之间不会自动同步。
